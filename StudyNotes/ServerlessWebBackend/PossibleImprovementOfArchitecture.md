# Improvement of Architecture
## Possible Improvement of Architecture
- Optimization of the architecture by using [AWS Lambda Power Tuning](https://github.com/alexcasalboni/aws-lambda-power-tuning).
- AWS Lambda Powertools is a suite of utilities for AWS Lambda functions to ease adopting best practices such as tracing, structured logging, custom metrics, and more. It can be used to improve the observability and performance of Lambda functions in the architecture.
- AWS Lambda execution environment reuse allow to optimize the performance of Lambda functions by reusing the execution environment for subsequent invocations. This can reduce cold start times and improve overall performance.
